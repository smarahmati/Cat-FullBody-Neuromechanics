Numerical functions and the run/view/export scripts. Start with the clickable code map.

  • model configuration — Code that defines parameter names, validates their organization and locates project files. To change physical values for a simulation, edit Data/Model_Parameters.
  • neuromechanics — Functions that calculate excitation, activation, muscle and tendon forces, paw contact, coupled body motion and output comparisons. Each file represents a named part of the calculation.
  • simulation tools — Commands for running the model, playing its saved movement, exporting figures and preparing documentation. The root run.py is the normal entry point.
