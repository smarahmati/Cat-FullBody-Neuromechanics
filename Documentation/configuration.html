Maximum isometric muscle force

F0 is the maximum isometric muscle force along the tendon direction (N): the active reference force at full activation, optimal fiber length and zero fiber velocity, including the constant pennation projection. It is not tendon failure strength or a ceiling on total tendon tension. The tendon transmits force through elastic stretch. The parameter max_isometric_muscle_force_along_tendon_N stores this value; do not apply the pennation cosine again.

How to read the parameter tables

Source value is the verified number from the author’s original work or cited literature, in the listed units. Value used in this model is the number actually applied in the simulation. What changed and why identifies the difference and documented reason. If the source is unavailable, the table explicitly says “Not established”; that value is an assumption, estimate or fitted value.

Inspecting the excitation input

The prescribed dimensionless cycle is in excitation_cycle.tsv. The channel dictionary identifies each muscle. The input is fixed before the simulation. Parameter edits are applied only by computing a new trial.

Changing an attachment

Use ATTACHMENT_MAP.html to locate the site’s bone and local frame. An edited site moves with that bone. Changing it changes the routed MT length and its derivatives (moment arms), then force equilibrium and moments. For source pulley paths, routing.py is authoritative; edit its named radii/angles consistently rather than moving a dynamically recomputed tangent site. Wrapping is analytic/native; it does not collide muscles against a detailed mesh surface.
