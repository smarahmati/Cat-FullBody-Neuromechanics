Documentation formats and hosting

Reading, maintaining and hosting the project documentation.

Read formatted guides inside GitHub

The repository contains Markdown guides as well as HTML. Start with README.md on GitHub and follow its relative links. Each documented folder has a README with descriptions and links. Markdown supports formatted scientific text, equations, tables and figures without a separately published website. A private repository restricts these guides to authorized readers.

Read the styled and interactive version locally

Download or clone the whole project, extract it, and open START_HERE.html in a browser. The linked HTML pages, local figures, muscle selector, simulation video and interactive time windows work from the downloaded folder. External papers still require internet access. GitHub's file browser displays HTML source rather than running it.

Optional public website

The supplied hosting workflow requires a public repository and the Actions variable PUBLISH_DOCUMENTATION_WEBSITE=true. For private reading, use the repository's Markdown guides or the downloaded HTML.

  1. In the public repository, select Settings → Pages → Source → GitHub Actions.
  2. Add PUBLISH_DOCUMENTATION_WEBSITE with value true under Settings → Secrets and variables → Actions → Variables.
  3. Run Actions → Documentation website. The deployment output contains the website address.

Hosted pages are public. Repository access permissions do not protect a standard public Pages site. See GitHub's Pages documentation.

Regenerate the Markdown guides

After editing the HTML guides or equation source, run this from the project root:

python Code/simulation_tools/generate_github_guides.py

The generator preserves scientific content, rewrites navigation to Markdown or actual source code, and splits long parameter tables into readable pages. The root README is maintained separately. It does not change the simulation.

Equations in the GitHub guides are self-contained SVG figures. Their editable LaTeX is in equations.json and the figure source catalog. Building a new or changed equation figure also requires Node.js and the pinned MathJax renderer; the simulator does not need Node.js. Install the renderer once from the project root:

npm install --prefix Code/simulation_tools/equation_renderer

Unchanged figures are reused. Each parameter entry presents its source and applied values in a two-column table; select the entry to see all fields.

Optional local website build

python Code/simulation_tools/build_documentation_website.py --output _site --include-untracked

Choose a new or empty output directory. This packages the HTML and checks its local links; it does not publish anything. Large numerical downloads remain in the repository. Local private papers, restricted meshes and ignored runs are excluded.
