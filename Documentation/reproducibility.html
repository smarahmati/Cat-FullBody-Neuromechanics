Install, run and reproduce intact walking

Start here · Find a file

This repository contains the inputs and implementation for one fully forward, mechanically coupled intact-cat model. Paths below are relative to the downloaded project root.

1. Install Python and dependencies

The supplied environment uses Python 3.12.9 on Windows.

python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-lock.txt

In PyCharm select this project’s existing .venv/Scripts/python.exe interpreter. On macOS/Linux use .venv/bin/python; those platforms are not verified here. MuJoCo visualization needs OpenGL; Tkinter is required for the controls.

2. Compute walking

python run.py --seconds 6 --gui
python reproduce.py --gui
python run.py --seconds 60 --no-gui --output User_Simulations/my_intact_trial

The first command computes six seconds before opening the viewer. reproduce.py computes the complete 60-second intact case. You can also edit SIMULATION_SECONDS and SHOW_GUI at the top of run.py. The GUI displays computed results after integration; it does not prescribe the motion.

3. View the supplied result

python view.py --run Simulation_Results/Intact_Walking

Use Play/Pause, Reset/Start, Middle, End, Go to time or the slider. Plots use a four-second window and absolute simulation time. Select one limb, joint and muscle. Display normalization uses a fixed intact input peak; raw excitation and activation remain available in the exports.

4. Inspect or change model inputs

Data/Model_Parameters holds anatomical, mechanical, activation, contact and solver values. Data/Muscle_Excitation_Input holds the prescribed cycle and channel dictionary. Save edits and run again. Every new calculation reads these values; an existing animation remains a saved result.

5. Find calculated variables

Intact_Walking contains joint kinematics, GRFs, excitation, activation, muscle force, moment arms, muscle moments and body motion. The output dictionary defines units and signs. Parameters, comparison references and implementation copies identify the exact calculation.

6. Verify reproducibility

python Verification/verify_intact_walking.py

See complete numerical reproduction for tolerances. This package reproduces predictions from the supplied calibrated values; it does not rerun the entire parameter-estimation process from raw recordings. The estimation methods identify measured, estimated and assumed quantities.
