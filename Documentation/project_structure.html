Project folders and files

Start here · Find a file

Start with run.py. Model parameters, prescribed excitation, experimental references and computed results have separate, descriptive folders. Each folder has a navigation guide.

Names and scientific identifiers

Scientific muscle channel identifiers are defined in the muscle dictionary. Original research filenames remain unchanged for traceability. README.md, index.html and __init__.py follow standard GitHub, website and Python conventions.

Path from project rootPurpose
run.pyCompute a NEW fully forward trial, optionally opening the result viewer.
view.pyOpen an already computed trial without recalculating it.
reproduce.pyRecompute the complete 60-second intact walking simulation.
Code/neuromechanicsFunctions that calculate excitation, activation, muscle and tendon forces, paw contact, coupled body motion and output comparisons. Each file represents a named part of the calculation.
Code/model_configurationCode that defines parameter names, validates their organization and locates project files. To change physical values for a simulation, edit Data/Model_Parameters.
Code/simulation_toolsCommands for running the model, playing its saved movement, exporting figures and preparing documentation. The root run.py is the normal entry point.
Data/Model_ParametersEditable values for body mass and inertia, joints, muscle attachments, activation, muscle–tendon mechanics, contact and the initial state. Source-to-model tables explain the origin and applied value of each documented parameter.
Data/Muscle_Excitation_InputThe excitation waveform supplied to every muscle channel. excitation_cycle.tsv stores one cycle of dimensionless commands between 0 and 1; the simulator repeats this cycle and computes activation from it.
Data/Experimental_Reference_DataJoint angles, paw forces and EMG used to assess the prediction. RH is recorded, LH is an assumed mirror, and forelimb references come from a separate study. These curves do not drive the motion during a forward run.
Data/Original_Study_DataOriginal numerical tables and MATLAB files from the hindlimb and forelimb studies, retained to trace the scientific sources. The organized parameter and excitation files define the inputs used by run.py.
Data/Skeletal_GeometryThe connected body and joint structure and its geometric data. This determines where forces act and how segments move. Optional bone surface meshes change the appearance, not the mechanical calculation.
Simulation_Results/Intact_Walking60-second intact forward simulation, raw states and experimental comparisons.
VerificationExecutable equation checks and complete intact-walking reproduction.
Documentation/ReferencesScientific papers, citations and links to original sources.
Documentation/Figures_and_VideosScientific comparison plots, muscle schematics and walking animation.
