Reproducibility means computing the supplied intact trajectory from the documented inputs, parameters and equations. Experimental agreement is evaluated separately in Scientific comparisons.

Complete numerical reproduction

python Verification/verify_intact_walking.py

This integrates 60 seconds and compares the full saved time series: body and joint positions/velocities, excitation, activation, muscle force, fiber/tendon states, paw-pad indentation and raw contact forces. Relative tolerance is 10−7, absolute tolerance 10−8 in each array’s native units; shapes and the fall outcome must also match. A mismatch produces an error status.

New arrays and comparisons are saved in a local Simulation_Results/Verification_Runs folder. These generated files are excluded from Git. The distributed intact result is not overwritten. Floating-point and compiler differences can affect long trajectories; a failed comparison requires investigation.

Equation and software checks

python -m unittest discover -s Verification -v

These executable checks cover periodic prescribed input, configuration application, passive muscle force, tendon continuity, contact-force signs and friction limits, numerical regression and documentation navigation. They are software verification, not experimental validation.
