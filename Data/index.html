Authoritative input, parameters, geometry and experimental reference data.

  • Experimental Reference Data — Joint angles, paw forces and EMG used to assess the prediction. RH is recorded, LH is an assumed mirror, and forelimb references come from a separate study. These curves do not drive the motion during a forward run.
  • Muscle Excitation Input — The excitation waveform supplied to every muscle channel. excitation_cycle.tsv stores one cycle of dimensionless commands between 0 and 1; the simulator repeats this cycle and computes activation from it.
  • Model Parameters — Editable values for body mass and inertia, joints, muscle attachments, activation, muscle–tendon mechanics, contact and the initial state. Source-to-model tables explain the origin and applied value of each documented parameter.
  • Skeletal Geometry — The connected body and joint structure and its geometric data. This determines where forces act and how segments move. Optional bone surface meshes change the appearance, not the mechanical calculation.
  • Original Study Data — Original numerical tables and MATLAB files from the hindlimb and forelimb studies, retained to trace the scientific sources. The organized parameter and excitation files define the inputs used by run.py.
